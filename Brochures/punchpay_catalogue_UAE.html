Features & functions

Everything you need to run
attendance and payroll

One cloud platform — from punch capture to WPS bank file. Built for UAE SMEs, multi-branch teams, and growing headcounts.

Android face attendance kiosk

Turn any Android phone/tablet into a reception punch station. Face recognition IN/OUT — no fingerprint machine required.

  • One-time face enrollment per employee
  • Branch kiosk code + settings PIN
  • Same punch → payroll path as biometrics

Optional biometric devices

Already own ZKTeco (or compatible) machines? Connect via cloud ADMS — punches sync automatically to PunchPay.

  • No on-site PC required for ADMS mode
  • Device register, activate, last-seen status
  • Mix Android kiosk + devices if needed

Live attendance dashboard

See who’s in, on break, or absent — in real time. Weekly presence trend at a glance.

  • Today present / total headcount
  • Lunch break & absent lists
  • 7-day attendance chart

Attendance management

Monthly and daily views with punch-level detail. Fix mistakes without spreadsheets.

  • Present, absent, late, overtime
  • Manual / bulk punch entry
  • Edit punch time & type

Shifts & work rules

Define timings once — the system applies them fairly across your team.

  • Shift start/end, grace, lunch minutes
  • Weekly offs & company holidays (paid)
  • Late & lunch-over deductions
  • No-leave incentive option

Employee directory

One place for workforce records linked to salary, shift, and branch.

  • Employee code, salary, join date, status
  • UAE fields: IBAN, labour card, MOL
  • Search, filter, activate / deactivate

AED payroll engine

One-click month-end payroll from attendance — transparent net salary every time.

  • Gross, OT, deductions, advances, net
  • Gratuity / end-of-service on payslips
  • Dubai timezone · UAE payroll rules

WPS salary file export

Download monthly WPS-compatible CSV ready for bank salary transfers.

  • IBAN & labour card supported
  • Filter by branch / period
  • Built for UAE bank submissions

WhatsApp payslips & PDF

  • Instant delivery to employees
  • No printing required
  • Attendance, payroll & OT reports (CSV/PDF)

Multi-branch & advances

Run several locations under one company account. Track salary advances automatically.

  • Branches with separate headcount
